# submissions/

Staging area for the actual deliverables named in `COMPETITION.md`'s "Submission format"
section (repo link, demo video, live-demo notes, devpost writeup, etc.) — check that section
before assuming what belongs here. Unlike `logs/` and `scratch/`, this directory is **not**
gitignored by default: submission artifacts are usually the point of a commit, not something to
hide. If a specific file here turns out to be large/binary (e.g. a demo video), gitignore that
file individually rather than the whole directory, and host it externally with a link checked in
instead.
