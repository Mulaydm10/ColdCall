# Glossary

Prevents naming drift across sessions and agents. Add a term when you notice two people (or an
agent and a human) using different words for the same thing.

| Term | Meaning |
|---|---|
| Main Agent | `Mulaydm10` — sole authority over LOCKED files; see `GOVERNANCE.md`. |
| LOCKED | A file opening with the LOCKED banner; edit only via the Main Agent, logged in `GOVERNANCE.md`'s audit table. |
| STATE vs worklog | `STATE.md` = overwritten live snapshot of what's true now. `worklog.md` = append-only dated+timestamped history. If they disagree, STATE wins. |
| `ADR-####` | A design/stack decision record in `design/decisions/`. |
| `Q-####` | An open question in `research/open_questions.md`. |
| `EXP-####` | A logged experiment/spike in `experiments/experiment_log.md`. |
| `DEMO-####` | A numbered demo scenario in `DEMO.md`. |
| Work claim | A row in `STATE.md`'s claims table marking a surface as being actively worked, per `AGENTS.md`. |
